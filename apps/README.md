# Applications

Application surfaces are composed per client via the Solution Contract.

Expected surface families:
- customer_app — Flutter-first customer/B2B mobile application
- storefront — Next.js/React commerce web
- seller_portal — marketplace/partner surface
- commerce_admin — provider admin plus Agency extensions
- ops_console — cross-system exceptions, jobs, reconciliation, approvals
- widgetbook — Flutter component/pattern review
- storybook — web component/pattern review

Do not duplicate business rules in UI applications. Business rules belong to domain/business contracts.
